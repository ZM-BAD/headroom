# Acceptance Checklist

**真机验收清单** — 每一行必须在真实浏览器 + 真实 AI 平台页面上手动验证并打勾。
自动化（typecheck / lint / unit test / build）不能替代这份清单 — 它们只验证逻辑，
不验证浏览器 API、平台 API 和真实用户交互。

> **使用方式**：每次真机测试前，复制一份到本地，逐项打勾。完成后把结果贴到
> commit message 或 PR 描述中。

---

## 003 跨设备对账（真机 — 核心风险区）

### 打开即对账

- [ ] **003-01** 第一次装扩展 → 打开已有对话 → 仪表盘从 0 爬到真实累计（不等网络）
- [ ] **003-02** 关面板再开 → 秒开（读本地缓存，不等 Upstash）
- [ ] **003-03** 在有 Upstash 记录的对话中再聊一轮 → Upstash 值更新（覆盖写整条）

### 跨设备（需要两台设备 / 两个浏览器 Profile）

- [ ] **003-04** 设备 A 聊 5 轮 → 设备 B 打开同对话 → B 显示 5 轮累计（不是 0）
- [ ] **003-05** 设备 A 聊完后设备 B 再聊 2 轮 → 设备 A 打开显示 7 轮
- [ ] **003-06** 对话包含移动端聊的轮次（如果有）→ 纳入累计

### 断网恢复

- [ ] **003-07** 断网状态下聊 2 轮 → DevTools Console 出现 `cloud sync failed` warn
- [ ] **003-08** 恢复网络 → 打开同一对话 → 对账补回（累计含断网期间的轮次）

### union 合并正确性

- [ ] **003-09** 50+ 轮长对话 → 打开 → `totalTokens` 合理（不翻倍、不丢失）
- [ ] **003-10** 重新生成某轮后打开 → 该轮 token 更新为重新生成后的值，轮数不变

### 删除联动

- [ ] **003-11** 网页删对话 → 本地缓存 + Upstash key 都消失
- [ ] **003-12** 设备 A 删对话 → 设备 B 打开同对话首页（或等 alarms 10min）→ Upstash 记录被清理

### 僵尸清理

- [ ] **003-13** 等 10min → DevTools Console 无 `zombie cleanup failed` 错误
- [ ] **003-14** 打开平台首页 → 不报错（首页触发清理）

### 对账频率控制（debounce）

- [ ] **003-15** 在 DeepSeek 快速连续点击 3 个不同对话 → 面板只在最后一个停留 ≥2s 后才拉完整历史
- [ ] **003-16** 快速切对话时，仪表盘立即切换（从缓存读，不卡顿）
- [ ] **003-17** 回答完毕后立即拉历史（REFRESH_HISTORY，不受 debounce 影响）

### LRU 淘汰

- [ ] **003-18** 大量对话（50+）后 → `storage.local` 用量不超过软阈值太多
- [ ] **003-19** 被淘汰的对话重新打开 → 从 Upstash 恢复（不丢数据）

## 跨浏览器深度 QA（Firefox 差异点）

> 冒烟通过后，逐项验证 Firefox 与 Chrome 的已知差异。

### Side Panel 差异

- [ ] **CB-F01** Firefox 使用 `sidebarAction`（非 `sidePanel`）——面板打开/关闭生命周期与 Chrome 一致
- [ ] **CB-F02** Firefox 侧边栏是全局的（不能像 Chrome 那样按 tab 关闭）——确认切换非平台页时面板行为合理

### Service Worker 生命周期

- [ ] **CB-F03** Firefox 用 event page 而非 service worker ——确认重载扩展后、浏览器重启后核心功能正常
- [ ] **CB-F04** SW 被 evict 后重新唤醒 → 消息通道恢复、`alarms` 继续调度

### webRequest 行为差异

- [ ] **CB-F05** Firefox 的 `webRequest.onBeforeRequest` 支持 `requestBody`——确认删除拦截正常
- [ ] **CB-F06** `onCompleted` / `onErrorOccurred` 触发时机与 Chrome 一致——SSE 流关闭 = 回答完毕判定准确

### 存储差异

- [ ] **CB-F07** Firefox `storage.local` 配额基于磁盘空间（非 Chrome 的 10 MB）——确认大量对话后无异常
- [ ] **CB-F08** `storage.local` 读写延迟在可接受范围内

### alarms 差异

- [ ] **CB-F09** Firefox `alarms` 最小 interval ≥1 min（Chrome 支持 10s）——僵尸清理 10min 周期不受影响

### 综合

- [ ] **CB-F10** 至少一个其他平台（ChatGPT/Kimi/Qwen 任选一）完整走通"打开→聊一轮→删除→切对话"流程
